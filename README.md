# Lovec vltavínů: Na zelené vlně — Reborn 5.4

Finální sjednocená verze browser hry. Hlavním cílem je projít jihočeské lokality, sestavit nejlepší sbírku a dorazit do KD Slávie na akci **Na zelené vlně**.

## Hlavní novinky
- Besednice je vrchol hry s filmovou krádeží a třífázovým bossem;
- výrazné upozornění „BYL JSI OKRADEN OD FEŤÁKA“;
- lepší animace všech postav a bossů;
- opravená viditelnost hráče v nočním levelu;
- sjednocené cíle, HUD a prezentace levelů.

## Nasazení
Rozbal obsah ZIPu přímo do kořene GitHub repozitáře. `index.html` musí zůstat v kořeni a `.github/workflows/pages.yml` musí být zachován.
